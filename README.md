# Java Console Projects

This repository contains two beginner-friendly Java console applications developed using Object-Oriented Programming (OOP) concepts.

## 📌 Projects

1. **Calculator Application**
2. **Bet Game**

Both projects are written in Java and run in the terminal using a menu-driven interface.

# 🎲 Bet Game

A simple number prediction betting game where users can deposit money, place bets, and manage their balance.

## Features

- 💰 Add Money
- 💸 Withdraw Money
- 🎯 Predict a number between 1 and 10
- 🎲 Random number generation
- 🏦 Balance management
- 📜 Transaction History
- 🚪 Exit

## Game Rules

1. Deposit money into your wallet.
2. Enter the amount you want to bet.
3. Predict a number between **1 and 10**.
4. If your prediction matches the randomly generated number:
   - You win the bet.
5. Otherwise:
   - The bet amount is deducted from your balance.

## Technologies Used

- OOP (Classes & Objects)
- Scanner

- ArrayList
